# Poster quality gate

- Communicate one primary takeaway, not a compressed paper.
- Use an asymmetric editorial structure rather than repeated cards.
- Give the strongest result the largest visual area.
- Keep methods and provenance visible without competing with the conclusion.
- Use no more than two font families and a restrained accent palette.
- Check reading order at thumbnail size and text legibility at intended viewing distance.
- Use only licensed or user-owned media; record sources.
- Verify dimensions, bleed, color expectations, and output format before print.
