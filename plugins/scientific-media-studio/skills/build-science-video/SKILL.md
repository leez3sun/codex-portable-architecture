# Build Science Video

## Procedure

1. Complete cross-platform audiovisual research and record references, timestamps, transferable patterns, and failure modes.
2. Define the audience, aspect ratio, duration, platform, scientific claim, and source manifest.
3. Propose three distinct narrative concepts and select one using accuracy, originality, retention, and production risk.
4. Write a beat-level storyboard before implementation. Mark every frame source as solver output, measured data, explanatory diagram, or illustrative footage.
5. Use installed Remotion skills for programmatic composition and captions. Use `../../scripts/media_pipeline.py` for probing, thumbnails, frame extraction, transcoding, and delivery.
6. When the user provides liked/disliked frames, recurring placement corrections, or aesthetic feedback, invoke `learn-video-preferences`. Render and score representative stills before a full render.
7. Keep legends, units, time meaning, deformation scale, boundary conditions, and uncertainty readable.
8. Verify the opening hook, pacing, representative frames, captions, audio, duration, resolution, frame rate, and codec.

Read [references/storyboard-and-qa.md](references/storyboard-and-qa.md) before building the composition.
